# Social_media__website_in_PHP
 Website is designed in PHP,HTML,MySQL,CSS And Bootstrap.
 
I have tries to copy the features of facebook like
  posting your thoughts,
  Sending friend request,
  Sending message,
  blocking a user,
  searching a user by its name,
  searching a user by its email,
  uploading photos 
  any many more
One additional feature i have added is you can send a Email to a user of the network.
